# 棋灯 (KITO)

中級者以上に向けたブラウザ将棋コーチの試作。ローカルで動くやねうら王の実解析を使います。

## 起動

Node.js 20.19+ / 22.12+。

```sh
npm ci
npm run build
npm run dev
```

http://127.0.0.1:5173 を通常のブラウザで開きます。初回の `npm run build` はエンジンを public にコピーします。エンジンには SharedArrayBuffer と COOP/COEP ヘッダーが必要です。Viteの開発・プレビュー、配信する `_headers` に設定があります。iframe内で動作しない場合は独立タブで開いてください。

## 機能

- やねうら王 NNUE K-P / SuishoPetite 2021-11との対局（1スレッド、ハッシュ32MB）
- 合法手、成り選択、持ち駒、二歩、打ち歩詰め、王手・詰み
- 4回反復の千日手、連続王手の千日手、投了
- 上位3候補の実評価・深さ・読み筋、盤上で読み筋再生
- 段階的なヒントと盤上の事実に基づく定型解説
- SFEN / USIインポート、USIエクスポート
- 局面と考えをブラウザに保存、復習、ノートJSON出力

## 対話コーチ UIプレビュー

「コーチと話す」に、会話例・局面共有表示・質問候補・入力と送信の表示例があります。入力は外部送信せず、APIは呼び出しません。会話欄は局面ごとに分け、ページを再読み込みするとリセットされます。エンジンの実解析は「候補手・解析」タブから使えます。

## 現在の境界

- **生成AIの自然言語対話は未接続**。説明は計算された事実と定型文で、生成AIの出力ではありません。
- 入玉宣言、時間切れ、KIF/CSA入出力、クラウド同期は未対応。
- 評価値は先手視点。勝率や段級位ではありません。短時間の順位は変わります。
- 「振り返る」等の手の比較は、その手が実測されたMultiPV候補に含まれた場合に限ります。含まれない手を推定で採点しません。
- 復元時は意図せずAIが指さないよう自由研究モードになります。
- ブラウザ保存が使えない場合はトーストを表示。棋譜・ノートをダウンロードしてください。

## 検証

```sh
npm test
npm run build
```

## 次の開発

強いエンジンの出力（SFEN、合法な候補、深さ、評価の視点、PVと各局面の事実）に基づくサーバー側生成AI解説。候補手の狙いを質問し、悪手の反証手順を比較する。APIキーはブラウザに置かない設計にする。
